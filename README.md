# Billan Software Solutions Website 🌳

Official website for Billan - Software solutions from roots to leaves.

## 🌱 About

Billan provides comprehensive software development services, from robust backend systems (roots) to beautiful frontend interfaces (leaves). Founded by Mugisha Billy-Chriss and Manzi Allan.

## 🚀 Features

- Modern, responsive design
- Animated UI elements
- Team profiles with GitHub integration
- Contact form with Formspree integration
- Mobile-friendly navigation
- SEO optimized
- Fast loading and performance

## 🛠️ Technologies Used

- HTML5
- CSS3 (with CSS variables and animations)
- JavaScript (ES6+)
- AOS (Animate on Scroll library)
- Font Awesome icons
- Formspree for form handling

## 📋 Prerequisites

- A Formspree account (free at [formspree.io](https://formspree.io))
- Git (for deployment)
